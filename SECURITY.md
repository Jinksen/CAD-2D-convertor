# Security policy

CAD2Maxwell processes CAD files locally. Treat untrusted CAD inputs as potentially hostile and avoid including proprietary models or personal paths in public reports.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository's Security tab when available. If that option is unavailable, open an issue requesting a private reporting channel without including exploit details, credentials, or sensitive CAD data. Maintainers will coordinate a private follow-up.

Include the affected version or commit, reproduction steps using synthetic data, expected and observed behavior, and potential impact.

## Supported versions

This project is pre-release. Security fixes are made on the `main` branch; older commits and development branches are not maintained.
