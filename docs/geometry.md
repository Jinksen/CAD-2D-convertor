# Geometry

Python with OpenCascade/OCP is the sole geometric authority. STEP/STP import reads through XCAF, which preserves assembly occurrences and source labels that a flat shape import would lose. Each imported solid is retained as an exact, located B-Rep shape in a process-local backend session. The import API returns metadata and bounds; the section API produces exact component-owned B-Rep wires and analytic 2D curves.

Import sets the XCAF document unit to millimetres before transfer. The STEP reader reports source units separately, and the response records the source-to-millimetre scale when recognized. Bounds and retained session shapes are in millimetres. Missing, conflicting, or unrecognized source units produce an `unknown_source_unit` diagnostic and no claimed scale. Void or non-finite body bounds are skipped with `invalid_body_bounds`; if no solids remain, import fails. No geometry healing is performed.

For each body, occurrence metadata takes precedence over product metadata. Source names and colors stay nullable when unavailable; generated display and ASCII-safe export names are separate fields. Stable component IDs derive from the source SHA-256, the XCAF occurrence path, and the solid ordinal, so an unchanged file keeps component identity across imports regardless of its absolute location. The random `import_id` identifies only the current backend session.

`POST /api/v1/imports/step` accepts `{"path":"C:/absolute/model.step"}`. Successful responses contain `import_id`, `path`, `sha256`, `source_unit`, `to_mm_scale`, `bounds_mm`, `component_count`, `components`, and `diagnostics`. Each component includes source/display/export names, source label reference, hierarchy, color and provenance where available, body ordinal, and bounds. Errors use a stable `{ "error": { "code": "...", "message": "..." } }` envelope. Non-absolute or non-file paths return 422, absent files 404, unreadable files 403, malformed or empty STEP content 400, and unexpected failures 500 without CAD data or tracebacks in the response.

`POST /api/v1/imports/step/file?filename=<name.step>` accepts a streamed local file from the desktop chooser. It rejects names with path separators or invalid Windows filename characters and files larger than 512 MiB. The temporary upload copy is removed after OpenCascade import; the response `path` is the original filename and the exact bodies remain in the import session. No cloud upload occurs.

`POST /api/v1/section` intersects every retained solid with an XY, XZ, YZ, or custom plane using OpenCascade. It assembles intersection edges into wires using shared topology only, without silently bridging gaps. It checks that every section edge was traversed and serialized. Plane-local coordinates use a right-handed basis. Line, circle, and ellipse parameters remain analytic in the DTO, and the exact wires remain in a process-local session. Closed wires are classified as outer or hole by exact planar containment parity. Ambiguous contact or negligible area fails classification. An unsupported curve fails the section request; an open wire or empty section has an explicit diagnostic. A central tolerance policy holds millimetre defaults.

Exact positive-area cross-component overlap validation uses planar OpenCascade faces with hole regions subtracted. Overlaps produce component-linked error diagnostics and block DXF export; edge-only contact has zero area and remains allowed. OpenCascade face validity rejects invalid planar contours, including the tested self-intersecting case, with a component-linked diagnostic. Duplicate/tiny-edge checks, B-spline transport, and complex-model Maxwell import verification remain to be implemented. The CLI can write an analytic DXF draft and manifest from a closed section, but its contours are not yet fully validated Maxwell regions. The current 2D viewport draws outlines only.

`POST /api/v1/export/dxf` accepts typed `import_id` and `section_id` and returns a ZIP containing `section.dxf` and `section.json`. It reads both summaries from backend sessions, rejects mismatches, and never accepts a filesystem output path. The archive remains a draft until geometry validation and complex-model Maxwell checks are complete.

`GET /api/v1/imports/{import_id}/preview` triangulates each retained component with OpenCascade and returns positions, normals, indices, component ID, and source color. The JSON preview has a 50,000-triangle cap and reports a clear error above that limit. Preview meshes are visualization artifacts only. Mesh slicing is not an acceptable substitute for exact sectioning. Significant repairs must be reported to the user rather than applied silently, and tolerances are centralized and unit-aware.
