# CAD2Maxwell 0.2.0

The desktop app is now native Rust (Rune) instead of React/Tauri. Geometry, API and DXF export are unchanged.

## Install

- `CAD2Maxwell_0.2.0_x64-setup.exe`: per-user install, no administrator rights; uninstall from Settings > Apps.
- `CAD2Maxwell_0.2.0_x64_portable.zip`: extract to a short path and run `CAD2Maxwell\CAD2Maxwell.exe`.
- Verify with `Get-FileHash <file> -Algorithm SHA256` against `SHA256SUMS.txt`. Builds are not code-signed; SmartScreen may ask once (More info > Run anyway).

## Upgrading from 0.1.x

- Run the new installer; it replaces the old install (the installer changed from NSIS to Inno Setup, so uninstalling 0.1.x first is cleanest).
- Projects (`.c2mproj`) open unchanged.
- UI preferences stored by the React app (localStorage) do not carry over; theme and number format reset.
- Service log: `%LOCALAPPDATA%\com.cad2maxwell.desktop\logs\backend.log`.

## Known gaps

- 3D triangles crossing the near plane are dropped, not clipped.
- 2D fills skip wires above 3000 points; filled regions with holes are painted over (export is unaffected).
- Sections with ~100k curves render at about 44 ms per frame.
- A GPU-capable Windows desktop is required.
