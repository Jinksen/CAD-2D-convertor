# CAD2Maxwell 0.3.0

Clearer workspace, settings dialog, IGES/BREP import, more export formats and safer projects. Exact geometry and the DXF default output are unchanged.

## Highlights

- Model tree with assembly folders, groups, material labels, context menu, multi-select and drag to group.
- 2D view with scale bar, grid, legend, measuring and exact region metrics; 3D view with axis triad and near-plane clipping.
- Settings dialog (Ctrl+,), advanced tolerances, named sections per project.
- Import STEP, IGES (solid B-Reps) and BREP.
- Export DXF with layer and colour modes, plus CSV, SVG, FEMM, Gmsh and PyAEDT; batch jobs support all formats.
- Unsaved-changes prompt, recent projects, welcome screen, autosave and recovery.
- Symmetry hint with explicit 1/N sector section.
- New logo and a documentation site: https://jinksen.github.io/CAD-2D-convertor/

## Install

- `CAD2Maxwell_0.3.0_x64-setup.exe`: per-user install, no administrator rights; uninstall from Settings > Apps.
- `CAD2Maxwell_0.3.0_x64_portable.zip`: extract to a short path and run `CAD2Maxwell\CAD2Maxwell.exe`.
- Verify with `Get-FileHash <file> -Algorithm SHA256` against `SHA256SUMS.txt`. Builds are not code-signed; SmartScreen may ask once (More info > Run anyway).

## Upgrading from 0.2.x

- Projects (`.c2mproj`) open unchanged; new fields are optional and 0.2 ignores them.
- Export manifest `schema_version` is now 2. Tools that read `section.json` should accept the new keys; default DXF output is the same.
- Open model clears the project path; save again to choose one.
- Settings moved to the dialog. Saved theme and number format still load.
- The demo motor now has `Stator_Assembly` and `Rotor_Assembly` folders.
- Service log: `%LOCALAPPDATA%\com.cad2maxwell.desktop\logs\backend.log`.

## Known gaps

- Exports remain `draft_unvalidated`; the Maxwell import checklist has only been run on simple samples.
- FEMM, Gmsh and PyAEDT outputs are tested structurally, not opened in those tools. FEMM and Gmsh reject ellipses.
- Motor-CAD DXF import is unverified; no preset.
- The window close button cannot prompt about unsaved changes; a recovery file is kept instead.
- IGES levels are not mapped; surface-only IGES is rejected.
- Picking one region among several of the same body for metrics is not available.
- 2D fills skip wires above 3000 points; sections with ~100k curves render slowly.
- A GPU-capable Windows desktop is required. Builds are not code-signed.
