# UX

The workspace follows a compact CAE/CAD panel layout: toolbar, model-tree area, central viewport, properties panel, and persistent status bar. The Milestone 0 shell provides these regions and clear empty/offline states.

The STEP import form accepts an absolute local path or a file selected through the system chooser. On success, the model panel lists bodies in source order, selection shows source and export names, hierarchy, dimensions, and source units, and import diagnostics appear below the workspace. The status bar reports the imported body count. A failed import leaves the prior model visible and shows the backend error beside the form. The 3D tab offers orbit, zoom, and click selection from display meshes generated by Python.

After import, the Section settings offer an editable offset for the selected XY, XZ, or YZ plane, or a custom plane given by its normal and offset. **Align to selected body** sets the custom plane to the selected sheet's plane. Compute Section requests exact curves from Python and draws component-colored outlines and classified region fills with holes. Clicking geometry selects its source component. Errors remain visible without discarding the imported model. Open or invalid sections remain outlines.

Selection synchronizes across the model tree, 3D preview, 2D section viewport, component-linked diagnostics, and properties. Switching viewport tabs preserves the current 2D section. A closed, classified section exposes a draft DXF download. Invalid planar faces and cross-component overlaps hide that action and show actionable errors. Controls must remain keyboard accessible with visible focus, status must never rely on color alone, and errors must be actionable. Expensive section operations will be debounced and provide progress rather than blocking the UI.

The visual direction is neutral graphite with restrained accent color, compact controls, and tabular engineering data instead of consumer-dashboard cards.

The workspace is bounded to the window height. Long component lists and diagnostics scroll within their panels so the drawing and status bar remain reachable. The ribbon exposes Open STEP, a named section-plane group, Compute, and DXF export; planes and Compute are disabled until a model is loaded, and DXF stays disabled until the computed section is exportable. Ribbon Compute and DXF open the Section settings so their results and saved path are visible. The 2D view explains its initial empty state, fits rendered section curves, offers fit and zoom controls, and reports intersected bodies plus actual region and diagnostic counts. Changing planes before an export download completes cancels the pending Save dialog.

The compiled trial opens a native Save dialog for the draft DXF ZIP. Successful saves report the chosen path and explain that the archive must be extracted for Maxwell. Cancellation leaves the section available; write failures appear as actionable errors. Moving or recomputing the plane clears the previous export notice.

Numbers and quantities follow ISO 80000-1, as described in [number-format.md](number-format.md). The Model Builder always shows **Units and Number Format**. It sets the display length unit, decimal places, decimal marker, digit grouping and trailing zeros. Section offsets and normals are typed in that notation, and the unit is shown beside the field. Geometry and DXF export stay in millimetres.
